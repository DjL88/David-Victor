# Round channel icons

13 individual circular channel badges. Transparent outside each circle.

Use `32x32` for a 32 CSS-pixel display, `64x64` for 2x pixel-density screens and `128x128` for 4x. Every file has the same square canvas and circular outer boundary; no labels are baked in. Keep accessible channel names in application UI.

Snappy Shopper is the corrected **red basket with blue wheels**, on pale aqua. It is extracted from the prior source artwork, not the incorrect pink wordmark. JET Go intentionally shares Just Eat artwork, but remains a separate direct-delivery channel in the map. Numeric Deliverect IDs are not assumed.

## Provenance and limitations
Other badges retain the user-approved design-sheet artwork as raster exports. These are not presented as verified official vector masters. No SVG/vector or trademark approval is claimed. Original brand-source assets remain separate in the earlier pack.

This archive is a local export. It does not itself change any GitHub branch or deploy the application.
